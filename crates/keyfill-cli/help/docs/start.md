# start — с чего начать

keyfill рендерит графику эфира и интерфейсов из TSX без браузера. Сцена — `defineScene({...})`
в `.tsx`, сценарий команд — `cues(scene, ...)` в `*.cues.ts`. Канал живого эфира —
`defineChannel({...})`: графику ставят на слои команды из журнала `*.journal.jsonl`
(keyfill docs channel). Любая команда принимает всё это.

Цикл работы:

1. Написать сцену или компонент; заготовка — `keyfill new <имя>` (keyfill docs project).
2. `keyfill check <сцена>` — нарушения `must` и правил на каждом кадре сценария. Код выхода 1, если
   есть ошибки; `next` подсказывает готовую команду `keyfill inspect`.
3. `keyfill dump <сцена> [--t момент]` — дерево сцены: геометрия, значения, движение, диагностики.
   `keyfill inspect <сцена> <узел>` — один узел: откуда пришло каждое значение (provenance).
4. `keyfill render` / `keyfill filmstrip` — посмотреть картинку; `keyfill video` — файл с альфой.
5. `keyfill test` — закрепить результат: `*.keyfill.test.ts` со снапшотами дампа и пикселей.

Понять, что есть в сцене: `keyfill schema <сцена>` — пропсы, компоненты, части, команды, маркеры.
Понять диагностику: `keyfill explain <правило>`; все правила — `keyfill explain`.

Темы справки: `keyfill docs <тема>`, список — `keyfill docs`.
