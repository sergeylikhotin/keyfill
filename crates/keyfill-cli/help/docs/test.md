# test — тесты сцен и снапшоты

Файл `*.keyfill.test.ts` рядом со сценой; запуск — `keyfill test` (все файлы проекта),
`keyfill test examples/lower-third` (каталог), `keyfill test x.keyfill.test.ts --name длинное` (часть имени).

    import { test } from '@keyfill/core';
    import scene from './scene';
    import script from './scene.cues';

    test('в эфире', { scene, bg: '#101820', scale: 0.5, expect: { snapshot: ['dump', 'png'] } });
    test('длинное имя', { scene, props: { name: 'Константин Константинопольский' }, expect: { snapshot: 'dump' } });
    test('сценарий', { scene: script, t: ['0..5', 'ready', 'out+0.1'], expect: { snapshot: 'dump' } });
    test('переполнение в dev', { scene: overflow, expect: { clean: false, snapshot: 'dump' } });

Случай: `scene` — сцена или сценарий; `props` — данные сцены (tsc сверяет со схемой); `t` —
моменты по грамматике времени (по умолчанию `settled`); `mode` (`dev`, `air`), `bg`, `scale` —
как одноимённые флаги.

Проверки:

- `clean` (по умолчанию true) — нет ошибок диагностики в момент. Диапазон в `t` (`'0..5'`) —
  нет ошибок ни на одном кадре; снапшоты на диапазоне не снимаются.
- `snapshot: 'dump'` — текстовый дамп момента без мест в исходнике (сдвиг строк кода снапшот
  не меняет). Расхождение показывается по узлам: `+` появился, `-` пропал, `~` изменился.
- `snapshot: 'png'` — пиксели. Допуск `tolerance: { channel: 2, pixels: 0.001 }`: насколько может
  отличаться канал и какой доле пикселей можно отличаться сильнее. При расхождении новый кадр
  и маска отличий (пурпурным) пишутся в `.keyfill/test/<путь снапшота>`.

Снапшоты лежат в `__snapshots__/<файл>/<случай>@<t>.dump.txt|.png` рядом с тестом и хранятся
в git. Нет файла — keyfill его пишет (`записан`); расходится — случай падает, а после намеренной
правки `keyfill test <файл> --update` перезаписывает снапшоты и удаляет снапшоты удалённых случаев.

`keyfill test` идёт из каталога `keyfill.config.ts`, если он есть: пути в дампах от него, и результат
не зависит от каталога запуска. Код выхода 1, если упал хотя бы один случай.
