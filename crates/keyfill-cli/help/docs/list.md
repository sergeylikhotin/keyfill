# list — элементы по данным: For

    <Box layout={column({ gap: 6 })} presence={{ in: stagger(0.06, fade([0, 1])), out: stagger(0.04, fade([1, 0])) }}>
      <For each={p.teams} by={(t) => t.id}>
        {(t, i) => (
          <Box layout={row({ gap: 12 })}>
            <Text>{() => String(i() + 1)}</Text>
            <Text>{() => t().name}</Text>
            <Text>{count(() => t().points)}</Text>
          </Box>
        )}
      </For>
    </Box>

`For` живёт внутри `Box`, рядом с обычными детьми. Функция элемента вызывается один раз на
ключ и получает аксессоры: `t()` — данные элемента, `i()` — место в списке. Читай их внутри
аксессоров (`() => t().name`), иначе значение не обновится (`keyfill explain signal.untracked`).

Ключ решает, что такое «тот же элемент», когда приходят новые данные (`update`, команда канала,
`ctx.set`):

- **тот же ключ** — те же узлы с новыми значениями: `transition` и `count` ведут их плавно;
- **новый ключ** — элемент монтируется и входит: своё `in` или, если его нет, каскад `stagger`
  контейнера по порядку среди добавленных вместе;
- **пропавший ключ** — элемент уходит через своё `out` или каскад `out` контейнера и удаляется,
  когда уход кончится. Пока он уходит, он остаётся на своём месте;
- **новый порядок** — переставляются только сдвинутые элементы. Перестановка мгновенная:
  плавный переезд строки — анимация геометрии (M5).

`by` обязателен для объектов (`by={(t) => t.id}`); у строк и чисел ключ — само значение. Ключ —
устойчивый id, а не место в списке: с ключом по месту удаление второй строки переписало бы все
строки ниже. Повтор ключа — warn `list.duplicate-key`, показан первый.

Адрес элемента в дампе — по ключу: `Standings#1/panel/box[0]/box[key=zen]`. Он не меняется при
пересортировке и росте списка, поэтому `inspect`, `check` и снапшоты тестов указывают на тот же
элемент. Элемент-компонент называется как экземпляр: `Row#3`.

Границы данных: `prop.list(item, { max: 8 })` отсекает лишнее ещё на входе; не влезает по месту —
`must={{ fit: true }}` на контейнере и шаги `else`. Пример — `examples/standings`.
