# start — с чего начать

kine рендерит графику эфира и интерфейсов из TSX без браузера. Сцена — `defineScene({...})`
в `.tsx`, сценарий команд — `cues(scene, ...)` в `*.cues.ts`. Любая команда принимает и то, и другое.

Цикл работы:

1. Написать сцену или компонент; заготовка — `kine new <имя>` (kine docs project).
2. `kine check <сцена>` — нарушения `must` и правил на каждом кадре сценария. Код выхода 1, если
   есть ошибки; `next` подсказывает готовую команду `kine inspect`.
3. `kine dump <сцена> [--t момент]` — дерево сцены: геометрия, значения, движение, диагностики.
   `kine inspect <сцена> <узел>` — один узел: откуда пришло каждое значение (provenance).
4. `kine render` / `kine filmstrip` — посмотреть картинку; `kine video` — файл с альфой.
5. `kine test` — закрепить результат: `*.kine.test.ts` со снапшотами дампа и пикселей.

Понять, что есть в сцене: `kine schema <сцена>` — пропсы, компоненты, части, команды, маркеры.
Понять диагностику: `kine explain <правило>`; все правила — `kine explain`.

Темы справки: `kine docs <тема>`, список — `kine docs`.
