# perf — время кадра

    kine perf <entry> [--t a..b] [--scale N]

Строит и рисует каждый кадр диапазона (по умолчанию — весь сценарий) и меряет стадии:

- `script` — команды сценария и вызовы JS до момента кадра (обычно ноль: JS работает только
  на командах);
- `motion` — значения движения в момент кадра;
- `layout` — раскладка, текст, `must` и перебор `else`;
- `raster` — рисование на CPU;
- `frame` — кадр целиком.

По каждой стадии — mean, p50, p95, max в миллисекундах; ещё время запуска сцены, число кадров
дольше бюджета `1/fps` и три самых долгих кадра. p95 кадра больше бюджета — предупреждение
`perf.budget` с самой дорогой стадией (код выхода 0: замер зависит от машины).

Замеры debug-сборки в разы медленнее release: поле `build` в отчёте говорит, какая сборка
меряла. `--scale 2` — кадр 4K из опорного 1080p.
