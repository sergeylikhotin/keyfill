# must — утверждения и деградация else

    <Text must={{ fit: true, contrast: 4.5 }}
          else={[{ shrinkTo: 32 }, { shrinkTo: 32, lines: 2 }, { shrinkTo: 32, lines: 2, ellipsis: true }]}>
      {name}
    </Text>

Утверждения:

- `fit: true` — текст или дети не переполняют блок (`kine explain must.fit`);
- `inside: 'titleSafe'` — узел внутри цели: safe area, `stage`, `parent`, часть компонента;
- `contrast: 4.5` — WCAG-контраст самого слабого цвета текста к фону под ним; фон — подложки
  предков; над прозрачностью нужен `--bg`;
- `visible: true` — ненулевой размер, хотя бы частично в кадре, прозрачность больше 0.

Шаги `else` независимые, как ViewThatFits: `else[k]` применяется сам по себе, без шагов перед
ним, поверх собственных `fit` и `look` узла. Шаг: `shrinkTo`, `lines`, `ellipsis`, `look`, `hide`.

Режимы:

- `--mode dev` (по умолчанию и в тестах): нарушение — ошибка с адресом узла и местом в исходнике;
  подсказка называет шаг `else`, который его исправит. Кадр рисуется как есть.
- `--mode air`: применяется первый шаг, при котором `must` выполнен; не помог ни один — последний.
  Применённый шаг виден в дампе (`[else[1]]`) и в предупреждении.

`must` проверяет графику в эфире: каналы, которые сейчас ведут presence или таймлайн (ширина
посреди появления), в проверке не участвуют.

Проверить весь сценарий: `kine check <сцена>`; один сегмент — `--t in`; диапазон — `--t 0..4`.
Встроенные проверки без `must`: `anchor.overflow`, шрифты, look, движение — `kine explain`.
